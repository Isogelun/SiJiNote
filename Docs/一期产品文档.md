## 0. 范围与优先级

### 0.1 优先级定义

| 优先级 | 含义 | 排期不足时 |
| --- | --- | --- |
| P0 | 一期必须交付，缺一项不能发布 | 不可降级 |
| P1 | 一期按排期交付 | 整节平移二期，并在总表备注标注 |
| 二期 | 一期不做 | 见附录 A |

### 0.2 一期范围

- **P0**：注册、登录、主界面、编辑界面、保存与同步、批注、用户操作、收藏、回收站、客户端更新。
- **P1**：搜索、导入导出、分享；导出可以先于导入交付。
- **明确不进一期**：团队空间、成员与角色、共享知识库、评论与提及、通知、多人协同编辑、企业独立部署。

### 0.3 相对上一版的主要变化

| 项 | 上一版 | 本版 | 原因 |
| --- | --- | --- | --- |
| 客户端基线 | Kotlin Multiplatform / Kuikly / Compose | Flutter + Dart + SQLite | 以真实设备上的编辑体验、数据可靠性和性能测试决定迁移；页面还原效果不作为依据 |
| 状态栏 | 未保存 / 保存中 / 已保存 / 离线 / 冲突 | 区分"本地安全"与"云端成功"，见 §5.2 | 原五态的"已保存"无法区分草稿是否落盘、是否上云 |
| 保存与同步 | 分散在编辑界面一节 | 独立模块，P0 | 一期最重要的端到端流程 |
| 收藏 | 隐含在主界面 | 独立规则，P0 | 技术方案列入必做 |
| 搜索 | 直接定义实现 | 增加加密路线前提，可能降级为客户端索引 | 服务端能否读正文未定 |
| 分享 | 只读链接 | 只读快照，可撤销，不含批注 | 与批注私有原则对齐 |
| 大纲 / 图片 / 表格 / 下划 / 颜色 / 荧光笔 / 居中 / AI · Copilot | 部分列为一期"争取" | 全部二期 | 编辑内核优先 |
| 企业账号 / 独立部署 | 二期建议 | 二期，与团队空间同批 | 涉及组织与角色模型 |

### 0.4 写法约定

1. 每节按「目标 → 界面元素 → 流程 → 规则 → 异常 → 本期不做」展开，末尾给验收。
2. 规则编号，沟通时直接引用「5.4 第 4 条」。
3. 验收标准必须可判定，不用"流畅""快速"这类词。
4. 技术方案里的验收目标在本文件 §15 汇总，不重复解释实现。

## 1. 登录

### 1.1 目标

已有账号的用户进入软件并保持登录态，不必每次重新输入；退出时草稿不丢。

### 1.2 界面元素

| 元素 | 类型 | 说明 | 规则 |
| --- | --- | --- | --- |
| 产品标识区 | 展示 | 名称 + 一句话定位 | — |
| 账号 | 输入框 | 邮箱与用户 ID 共用 | 必填；含 `@` 按邮箱校验，否则按用户 ID 校验（4–20 位，字母数字下划线） |
| 密码 | 密码框 | 可切换显示 | 必填，8–32 位 |
| 登录按钮 | 主按钮 | — | 账号与密码均非空才可点 |
| 去注册 | 文字链 | 跳转注册页 | 已填账号自动带入 |

> 一期不渲染"企业账号 / 独立部署"的登录方式切换，避免出现不可用入口。

### 1.3 流程

1. 启动 → 校验本地登录态 → 有效直接进主界面，无效显示登录页。
2. 输入账号密码 → 登录 → 成功进入主界面，落到上次打开的笔记。
3. 主界面「用户」→ 退出登录 → 二次确认 → 回登录页。

### 1.4 规则

1. 账号或密码错误统一提示「账号或密码错误」，不区分账号是否存在。
2. 连续失败 5 次锁定 60 秒，期间按钮显示倒计时且不发起请求。
3. 登录成功后保持登录态，重开应用不再要求登录。
4. 首次登录落到知识库首页；之后落到上次打开的笔记，该笔记已删除则回首页。
5. 退出登录先触发一次落盘（见 §5.4 第 3 条）；落盘失败时询问「保留草稿退出」还是「取消退出」，不允许静默丢弃。

### 1.5 异常与提示

| 情况 | 表现 |
| --- | --- |
| 断网 | 提示「网络不稳定，请重试」，保留输入 |
| 服务端异常 | 提示「服务异常，请稍后重试」，按钮恢复可点 |
| 账号锁定 | 按钮倒计时，输入框仍可编辑 |
| 登录态失效 | 清本地会话回登录页，登录后回到原页面 |

### 1.6 本期不做

- 企业账号（子账号关联主账号）
- 独立部署（服务端初始账密 + 部署 UID）
- 找回密码、修改密码、邮箱验证

**验收**

- [ ] 断网、服务端 5xx 时按钮 2 秒内恢复可点，输入内容不丢。
- [ ] 强制结束进程后重开，已登录账号直接进主界面。
- [ ] 有未同步草稿时退出，确认后重登可恢复草稿。

## 2. 统一通行证注册

### 2.1 目标

新用户注册完成即进入软件，不出现「注册成功请再登录」的断点。

### 2.2 界面元素

| 元素 | 类型 | 说明 | 规则 |
| --- | --- | --- | --- |
| 用户 ID | 输入框 | 登录与展示用 | 4–20 位，字母数字下划线，唯一，注册后不可改 |
| 邮箱 | 输入框 | 登录与联系方式 | 合法邮箱，唯一 |
| 密码 | 密码框 | — | 8–32 位 |
| 确认密码 | 密码框 | — | 与密码一致 |
| 注册按钮 | 主按钮 | — | 四项通过校验才可点 |
| 返回登录 | 文字链 | 回登录页 | 已填账号带回 |
| 用户协议 | 复选框 | 默认勾选 | 取消勾选按钮不可用 |

### 2.3 流程

1. 登录页「去注册」→ 注册页，账号带入。
2. 填写 → 注册 → 校验通过 → 自动登录 → 进入主界面。
3. 主界面可见引导知识库，内含 3 篇引导文档。

### 2.4 规则

1. 用户 ID 与邮箱唯一，比较忽略大小写。
2. 用户 ID 注册后不可修改；邮箱一期不可修改。
3. 注册成功即登录。
4. 引导库与账号在同一事务内创建；创建失败不影响注册，登录后可重试。
5. 重复提交（双击、弱网重试）只创建一个账号。

### 2.5 异常与提示

| 情况 | 表现 |
| --- | --- |
| 用户 ID 重复 | 字段下方提示，其余内容保留 |
| 邮箱重复 | 字段下方提示 |
| 两次密码不一致 | 确认框下提示，不发起请求 |
| 网络失败 | 提示重试，表单完整保留 |
| 引导库创建失败 | 提示「引导内容加载失败」并提供重试，不阻塞进主界面 |

### 2.6 本期不做

- 企业子账号注册、邀请加入
- 手机号注册、邮箱验证
- 修改用户 ID / 邮箱

**验收**

- [ ] 双开提交只产生一个账号。
- [ ] 引导库创建失败时仍能进主界面并重试成功。

## 3. 思迹笔记主界面

### 3.1 目标

登录后的默认落点：一眼看到知识库，并能进入具体知识库或笔记。

### 3.2 布局

```
┌──────────┬──────────────────┬──────────────────────────────┐
│ 侧边栏    │ 知识库列表         │ 知识库首页                     │
│ 知识库 ●  │ 我的第一个知识库    │ 封面                          │
│ 收藏      │ 工作              │ 名称 + 简介                    │
│ 存储空间   │ 生活              │ 统计：笔记数 / 最近更新          │
│ 回收站    │                  │ 内容目录（文件夹 / 笔记）        │
│ ─────    │ + 新建            │                              │
│ 用户      │                  │                              │
│ 设置      │                  │                              │
└──────────┴──────────────────┴──────────────────────────────┘
```

手机端侧边栏收进抽屉，一次只显示一栏，逐层返回。

### 3.3 侧边栏

| 分区 | 一期行为 | 规则 |
| --- | --- | --- |
| 知识库 | 默认选中，列出全部知识库 | 当前库高亮；列表底部「+ 新建」 |
| 收藏 | 展示收藏笔记，按收藏时间倒序 | 空态引导去收藏，不展示空列表 |
| 存储空间 | 显示「即将上线」，禁用 | 点击不跳转 |
| 回收站 | 进入回收站 | 展示已删除条数角标 |
| 用户 | 头像 + 昵称 | 菜单含账号信息、退出登录 |
| 设置 | 打开设置页 | — |

### 3.4 知识库列表

| 元素 | 说明 | 规则 |
| --- | --- | --- |
| 知识库条目 | 名称 + 笔记数 | 按创建顺序，一期不提供自定义排序 |
| 新建按钮 | 列表底部 | 输入名称后回车创建，成功进入首页 |
| 更多菜单 | 右键（桌面）/ 长按（手机） | 重命名、编辑简介与封面、删除 |

**规则**

1. 名称 1–50 字，同用户下忽略大小写唯一。
2. 新建后进入该库首页并展开目录树。
3. 删除需二次确认，告知「库内 N 篇笔记将一并进入回收站，30 天内可恢复」。
4. 删除后切到列表中的下一个库；无剩余则展示空态。

### 3.5 知识库首页

| 元素 | 说明 | 规则 |
| --- | --- | --- |
| 封面 | 顶部横幅 | png/jpg/webp ≤ 5MB；无封面用纯色占位 |
| 名称 | 页面标题 | 点击可直接重命名 |
| 简介 | 一段说明 | ≤ 200 字；为空时隐藏该区域 |
| 统计 | 文本 | 笔记数、最近更新时间 |
| 内容目录 | 文件夹与根级笔记 | 顺序与目录树一致 |
| 新建笔记 | 主按钮 | 在当前库根目录创建 |

### 3.6 引导知识库

1. 注册成功时由系统创建，名称「我的第一个知识库」。
2. 内含 `欢迎使用思迹笔记`、`Markdown 速查`、`批注怎么用` 三篇。
3. 与普通库权限一致，可改名、可删除；删除后不再重建。

### 3.7 设置

| 设置项 | 说明 | 默认 | 生效 |
| --- | --- | --- | --- |
| 账号信息 | 头像、昵称、用户 ID、邮箱（只读） | 昵称取用户 ID | 保存后立即 |
| 主题 | 浅色 / 深色 / 跟随系统 | 跟随系统 | 立即，重启保持 |
| 字号 | 小 / 中 / 大 | 中 | 立即 |
| 默认编辑模式 | 编辑 / 预览 | 编辑 | 下次打开笔记 |
| 导入 / 导出 | 见 §10 | — | — |
| 清理缓存 | 清图片缓存与临时文件 | — | 立即，不清草稿与登录态 |
| 关于与更新 | 版本号、检查更新 | 自动检查 | 见 §12 |

### 3.8 异常与提示

| 情况 | 表现 |
| --- | --- |
| 知识库列表加载失败 | 错误态 + 重试，保留页面框架 |
| 无任何知识库 | 空态 + 「新建知识库」 |
| 新建时名称重复 | 输入框下提示，不关闭弹窗 |
| 删除失败 | 提示重试，条目保留 |

### 3.9 本期不做

- 存储空间与附件配额
- 知识库自定义排序、拖拽
- 最近打开列表
- 知识库封面裁剪

**验收**

- [ ] 新账号进入主界面 1 秒内可见侧边栏与知识库列表（冷启动单列统计）。
- [ ] 无知识库时展示空态，创建后立即进入新库首页。

## 4. 思迹笔记编辑界面

### 4.1 布局

| 区域 | 桌面端（Windows / macOS） | Android |
| --- | --- | --- |
| 目录树 | 左侧固定栏，可折叠 | 独立页面，从主界面进入 |
| 工具栏 | 编辑区上方，横向排列 | 键盘上方浮动工具条 |
| 编辑区 | 中部，占满剩余宽度 | 整屏 |
| 状态栏 | 编辑区底部 | 吸附键盘上方 |
| 批注面板 | 右侧，可收起 | 底部抽屉 |
| 大纲 | 二期 | 二期 |
| AI · Copilot | 二期 | 二期 |

### 4.2 目录树

| 元素 | 说明 | 规则 |
| --- | --- | --- |
| 文件夹节点 | 可展开 / 收起 | 一期只允许一层，不允许嵌套 |
| 笔记节点 | 点击打开编辑区 | 同父级允许重名，以 ID 区分 |
| 新建按钮 | 顶部「+」 | 在当前父级新建文件夹或笔记 |
| 更多菜单 | 右键 / 长按 | 重命名、删除、移动到… |

**规则**

1. 层级固定「知识库 > 文件夹 > 笔记」，超过一层不允许创建，入口直接不展示。
2. 新建后立即行内重命名，默认名「新建文件夹」「无标题」。
3. 文件夹重名自动追加「（2）」；笔记允许重名。
4. 删除笔记进回收站，5 秒内可撤销；删除文件夹需二次确认并告知内部笔记数。
5. 删除当前打开的笔记时切到同层下一篇，没有则回知识库首页。
6. 一期不做拖拽，移动统一走「移动到…」。

### 4.3 工具栏

| 分组 | 按钮 | 一期 | 行为 |
| --- | --- | --- | --- |
| 编辑 | 撤销 / 重做 | 是 | 撤销栈 ≥ 50 步，500ms 内同类输入合并为一步 |
| 插入 | 新建 / 插入 | 是 | 插入链接与分割线 |
| 格式 | 字体大小 | 是 | 以「正文 / H1 / H2 / H3」实现，不做任意字号 |
| 格式 | 加粗、倾斜、划掉 | 是 | `**` `*` `~~` |
| 格式 | 下划、字体颜色、荧光笔 | 否 | 二期 |
| 块 | 列表 | 是 | 有序 / 无序 / 任务列表 |
| 块 | 表格、居中 | 否 | 二期 |
| 插入 | 图片、调整大小 | 否 | 二期 |
| 视图 | 编辑 / 预览切换 | 是 | 原表未列，写作必需 |

**规则**

1. 有选区时作用于选区；无选区时切换下一次输入的格式状态，输入完成自动复位。
2. 按钮状态跟随光标实时高亮；不可用项置灰。
3. 手机以底部工具条承载同一组能力，不压缩成图标网格。
4. 工具栏固定在编辑区顶部，不随正文滚走。

### 4.4 编辑区

| 元素 | 说明 | 规则 |
| --- | --- | --- |
| 正文区 | Markdown 源码编辑 | 中文输入法组词期间不触发格式化、解析与保存 |
| 预览区 | 渲染结果 | 与编辑区共用同一份内容，切换不丢光标 |
| 空态 | 新笔记 | 占位「开始输入…」，占位不写入正文 |

**规则**

1. 一期采用「整篇源码编辑 + 预览切换」；不做类 Obsidian 的块级预览。
2. **Markdown 原文是正文唯一来源。** 预览节点、字数、定位索引都是可重新生成的产物，不单独存储、不反向写回正文。
3. 支持语法：标题 H1–H6、粗体、斜体、删除线、行内代码、链接、有序 / 无序 / 任务列表、引用、代码块、分割线。
4. 暂不支持：表格、图片、内联 HTML、脚注、数学公式（二期）。
5. 切换预览只改变展示，不改内容；切回编辑光标回到原位置。
6. 粘贴只取纯文本，`\r\n` 统一为 `\n`；不做富文本转换。
7. 撤销栈按编辑事务记录，切换笔记时销毁。
8. 处理时机：输入停顿后统一做解析与定位，不允许每次按键都触发全文解析、全部批注重定位和网络请求。

### 4.5 状态栏

状态栏展示字数、上次保存时间（相对时间，每分钟刷新）与同步状态。状态定义与流转见 §5.2。

字数口径：中文每字计 1，连续英文单词计 1，不含 Markdown 标记与空白；数字按连续串计 1。

### 4.6 快捷键

| 操作 | 桌面 | Android |
| --- | --- | --- |
| 撤销 / 重做 | `Ctrl/Cmd + Z`、`Ctrl/Cmd + Shift + Z` | 工具栏按钮 |
| 切换编辑 / 预览 | `Ctrl/Cmd + /` | 工具栏按钮 |
| 加粗 / 斜体 | `Ctrl/Cmd + B`、`Ctrl/Cmd + I` | 工具栏按钮 |
| 搜索 | `Ctrl/Cmd + K` | 底栏搜索 |

### 4.7 大纲（二期）

一期不实现，不预留栏位。二期规格：取 H1–H3，点击跳转，滚动同步高亮，可收起。

### 4.8 本期不做

- 右侧 AI · Copilot
- 块级预览
- 大纲栏
- 图片、表格、下划、字体颜色、荧光笔、居中、调整大小
- 拖拽排序
- 多人协同编辑与实时协同

**验收**

- [ ] 发布构建在一万字中文笔记上，按键到出字 ≤ 50ms。
- [ ] 组词过程中不出现字符被改写、光标跳位或预览闪烁。
- [ ] 编辑 → 预览 → 编辑，光标位置与内容完全一致。

## 5. 保存与同步

### 5.1 目标

**"本地安全"和"云端成功"是两件事。** 用户关掉应用、断网、进程被杀，已标记为"已存本地"的内容必须还在；只有服务端确认后，才可以说"已同步"。

### 5.2 状态定义

| 状态 | 含义 | 展示 |
| --- | --- | --- |
| 未保存 | 有改动，尚未写入本地库 | 灰点「未保存」 |
| 已存本地 | 草稿与待同步操作已写入本地事务 | 蓝点「已存本地 · 待同步」 |
| 同步中 | 上传请求在途 | 旋转图标「同步中…」 |
| 已同步 | 服务端已确认该版本 | 绿点「已同步 · 刚刚」 |
| 离线 | 无网络，改动已存本地 | 橙点「离线 · 已存本地」 |
| 冲突 | 云端版本已更新且与本地分叉 | 红点「内容已在其他设备更新」 |
| 本地保存失败 | 写本地库失败 | 红点「保存失败」，必须可见 |

与上一版五态的对应：原「已保存」拆成「已存本地」与「已同步」；原「保存中」即「同步中」；原「离线」「冲突」口径不变。

> 状态栏同时展示两个事实：本地是否安全、云端是否跟上。压缩成一个词会让用户在断网时误以为内容已经上云。

### 5.3 流程

1. **本地提交**：输入停顿后，把草稿与待同步操作写入同一个本地事务；事务成功才显示「已存本地」，写盘失败必须提示。
2. **自动同步**：停止输入约 800ms 后尝试上传；切换笔记、切后台、关闭窗口时优先落盘，不把数据安全寄托在退出前最后一次网络请求上。
3. **服务端提交**：客户端提交操作 ID 与基础版本；服务端校验权限与版本，在事务内写入改动与新版本。
4. **确认**：收到对应版本的成功响应才标记「已同步」；旧请求的响应不能把后续新编辑误标为已同步。
5. **删除同步**：删除记录一并同步，防止离线设备重新上传"复活"旧笔记。

### 5.4 规则

1. 本地事务成功是「已存本地」的唯一依据；界面不得先显示成功再落盘。
2. 自动同步触发阈值 800ms；连续输入期间不产生多次上传。
3. 切笔记、切后台、关窗、退出登录时强制落盘一次；落盘等待上限 2 秒，超时询问用户。
4. 同步请求必须携带操作 ID；网络重试同一操作不得产生重复笔记或重复批注。
5. 每个写操作携带基础版本；服务端版本不一致时返回冲突，不覆盖。
6. 冲突时暂停该笔记的自动覆盖；本地与云端两份内容都保留，等用户选择。
7. 服务端保存每次改动的前一版本，供冲突对比与恢复使用。
8. 恢复知识库或文件夹时，只恢复随该次删除级联删除的内容；用户此前单独删除的保持删除。
9. 本地草稿按账号隔离，不跨账号读取。
10. 离线不阻断编辑；恢复网络后自动补传，补传顺序按操作产生顺序。

### 5.5 冲突交互

1. 打开冲突笔记或收到冲突响应时，状态栏变红并弹出对比面板：左侧本地、右侧云端，标出差异段落。
2. 提供三个动作：「保留本地并覆盖云端」「使用云端版本」「保留本地副本后使用云端」。
3. 未做选择前，两份内容都不丢失；关闭面板可稍后处理。
4. 选择结果作为一次新的写入提交，并记录处理时间。

### 5.6 异常与提示

| 情况 | 表现 |
| --- | --- |
| 写本地失败（磁盘满、无权限） | 状态栏红色「保存失败」，提示原因与可操作建议，不吞掉错误 |
| 上传失败 | 保持「已存本地 · 待同步」，按 1s / 2s / 4s 重试，之后每 30s 重试 |
| 长时间离线 | 状态显示「离线 · 已存本地」，恢复网络后自动补传 |
| 冲突 | 见 §5.5；处理前该笔记不再自动上传 |
| 启动时有未同步草稿 | 提示「检测到未同步的编辑」，可继续编辑或查看 |
| 服务端 5xx | 保留待同步队列，不丢操作 |

### 5.7 本期不做

- 自动合并（三方合并、字符级合并）
- 实时协同编辑与在线状态
- 增量同步协议（一期按操作队列补传）
- 跨设备草稿互相同步

**验收**

- [ ] 断网编辑 → 强制结束进程 → 重启，已显示「已存本地」的内容完整恢复。
- [ ] 弱网环境下同一操作重试 3 次，服务端只落一条记录。
- [ ] 两台设备改同一笔记，均不静默覆盖；冲突处理后两份内容都可取回。
- [ ] 旧请求的迟到响应不会把新编辑标记为「已同步」。
- [ ] 平板/手机离线删除笔记后，另一设备上线不会把该笔记复活。

## 6. 批注

### 6.1 目标

让用户在原文上留下自己的思考，且批注不污染正文——编辑、预览、导出、分享看到的永远是干净的 Markdown。

### 6.2 元素

| 元素 | 说明 | 规则 |
| --- | --- | --- |
| 浮动工具条 | 选中文字后出现 | 仅单段内选区；选区 ≤ 500 字；跨段不出现 |
| 高亮 | 无说明的标记 | 黄色底纹 |
| 批注 | 带说明的标记 | 底纹 + 虚线下划线 |
| 批注面板 | 右侧列表（手机为底部抽屉） | 按正文位置排序，失效与已解决沉底 |
| 批注条目 | 引文 + 说明 + 时间 | 点击跳转定位 |

### 6.3 流程

1. 选中文字 → 浮动工具条 → 「高亮」立即创建，或「批注」创建后聚焦输入框。
2. 输入说明 → 失焦 500ms 后保存。
3. 点击面板条目 → 正文滚动到对应位置并高亮 2 秒。
4. 条目菜单 → 删除（5 秒内可撤销）。

### 6.4 规则

1. **独立存储**：批注与正文分开存；编辑、预览、导出、分享都不向正文插入标记。
2. **锚点**：段落签名 + 起止偏移 + 引文快照 + 前后各 24 字上下文。
3. **定位顺序**：先验证原位置（签名 + 偏移）；不成立则用引文与上下文重定位；出现多个无法可靠区分的候选时，**保留批注并标记「位置可能已失效」，不得静默跳到另一个相同句子**。
4. **偏移口径**：由工程在接口契约中固定并写明单位；跨客户端与服务端的实现必须共用同一口径。验收覆盖中文、emoji、换行与重复引文四类文本。
5. 引文快照不随正文修改自动更新。
6. 批注仅本人可见；不随分享发布，不进入导出正文。
7. 区段重叠允许重复创建，不合并。
8. 一期只支持单段内选区；跨段批注二期。

### 6.5 异常与提示

| 情况 | 表现 |
| --- | --- |
| 跨段选择 | 不出现工具条，提示「一期仅支持在单段内批注」 |
| 选区超长 | 按钮置灰并提示上限 |
| 定位失败 | 条目保留并标记失效，可删除或复制引文 |
| 多处同文 | 标记失效并展示候选，由用户手动指认，不自动选择 |
| 保存失败 | 输入内容保留，提供重试 |

### 6.6 本期不做

- 跨段批注
- 模糊匹配与自动纠错式重定位
- 已解决状态、多色分类
- 批注搜索
- 协作批注与评论

**验收**

- [ ] 在含重复句子的段落中修改上下文字数，批注不跳到另一处同文。
- [ ] 含 emoji 与换行的段落中，批注高亮范围与原文一致。
- [ ] 导出 Markdown 与分享页中不出现任何批注标记。

## 8. 回收站

### 8.1 目标

给删除一个 30 天缓冲，避免误删不可恢复。

### 8.2 元素

| 元素 | 说明 | 规则 |
| --- | --- | --- |
| 条目列表 | 知识库 / 文件夹 / 笔记 | 按删除时间倒序 |
| 条目信息 | 名称、类型、删除时间、剩余天数 | 剩余 = 30 − 已过天数 |
| 恢复 | 条目操作 | 回到原位置 |
| 彻底删除 | 条目操作 | 二次确认，不可恢复 |
| 空态 | 无条目 | 文案 + 「返回知识库」 |

### 8.3 流程

1. 侧边栏「回收站」→ 列表。
2. 「恢复」→ 回原位置并从列表移除。
3. 「彻底删除」→ 二次确认 → 物理删除。

### 8.4 规则

1. 保留 30 天，到期由服务端定时清理，客户端刷新后不再展示。
2. 恢复笔记：原文件夹存在回原位；已删除回知识库根目录。
3. 恢复文件夹 / 知识库：只恢复随它级联删除的内容，用户此前单独删除的保持删除。
4. 恢复不改变更新时间；原位置被占用时追加到末尾。
5. 彻底删除同时删除附件，不可撤销。
6. 删除与恢复都要同步到其他设备；删除记录保留到清理为止，防止离线设备复活。

### 8.5 异常与提示

| 情况 | 表现 |
| --- | --- |
| 恢复时上级已彻底删除 | 提示「原位置已删除」，恢复到知识库根目录或提示先恢复上级 |
| 条目已到期被清理 | 刷新列表并提示「内容已过期」 |
| 彻底删除失败 | 提示重试，条目保留 |
| 离线恢复 | 允许，进待同步队列 |

### 8.6 本期不做

- 按类型筛选、站内搜索
- 批量恢复 / 批量彻底删除
- 回收站容量限制

**验收**

- [ ] 第 29 天可恢复，第 31 天不可见。
- [ ] 恢复知识库不会复活用户此前单独删除的笔记。

## 9. 搜索（P1）

### 9.1 前提

搜索的实现取决于 §14 的加密路线：服务端可读明文时走服务端检索；默认端到端加密时，服务端无法做正文检索，需改为客户端索引或按客户端能力降级。**加密路线未定之前，不承诺服务端搜索指标。**

### 9.2 目标

在全部知识库中按关键词找到笔记并跳到命中位置。

### 9.3 元素

| 元素 | 说明 | 规则 |
| --- | --- | --- |
| 搜索框 | 顶部 / 独立页 | 进入即聚焦；空串不请求 |
| 结果项 | 标题 + 命中片段 + 所属知识库 | 关键词高亮 |
| 空结果 | 无匹配 | 提示 + 「新建同名笔记」 |
| 历史关键词 | 最近 10 条（本地） | 可单条清除 |

### 9.4 规则

1. 范围为当前用户全部未删除笔记，跨知识库。
2. 排序：标题完全匹配 > 标题包含 > 正文包含；同级按更新时间倒序。
3. 中文按子串匹配，英文按词边界匹配，忽略大小写。
4. 单次最多返回 200 条，超出提示细化关键词。
5. 关键词超过 100 字截断并提示。
6. 输入停顿 300ms 后才发起请求。

### 9.5 异常与提示

| 情况 | 表现 |
| --- | --- |
| 无结果 | 空态 + 新建入口 |
| 请求失败 | 错误态 + 重试，保留上次结果 |
| 超时（5 秒） | 提示「搜索超时，请重试」 |
| 离线 | 提示「搜索需要网络连接」（客户端索引方案则改为本地检索） |

### 9.6 本期不做

- 离线搜索（视加密路线可能改为必做）
- 按标签 / 时间 / 知识库筛选
- 搜索批注内容
- 无限滚动

**验收**

- [ ] 约定数据规模下服务端 P95 ≤ 500ms（仅明文方案适用）。
- [ ] 中文关键词可命中，无需完全匹配。
- [ ] 点击结果跳到笔记并定位命中段落。

| 进度 | 进度条 + 文案 | 每 10 个文件更新；可取消 |
| 结果汇总 | 弹窗 | 成功数与失败明细 |
| 导出入口 | 笔记更多菜单 / 设置 | 单篇或全部 |

### 10.3 规则

1. 导入按 UTF-8 解析并去 BOM，`\r\n` 统一 `\n`。
2. 标题取首个 H1，没有取文件名，都没有用「未命名」。
3. 同名自动追加「（2）」，不覆盖。
4. 桌面导入文件夹时创建一层同名文件夹，更深层级压平，标题拼相对路径。
5. 导出文件名替换 `\ / : * ? " < > |` 为 `_`，长度 ≤ 100。
6. 导出当前正文，不含未保存草稿，不含批注。
7. 单文件超过 5MB 跳过并计入失败明细。

### 10.4 异常与提示

| 情况 | 表现 |
| --- | --- |
| 类型不支持 | 跳过并列入失败明细 |
| 编码错误 | 跳过并注明原因 |
| 部分失败 | 成功项保留，列出失败文件名与原因 |
| 导入中断 | 已完成文件保留，不回滚 |
| 导出失败 | 提示重试，不生成半成品 |

### 10.5 本期不做

- 图片与附件导入导出
- PDF / Word / HTML 导出
- 语雀、Notion 等平台迁移
- 定时自动备份

**验收**

- [ ] 导出再导入，正文与目录结构一致。
- [ ] 导入 100 个文件进度可见，失败项可定位。

## 11. 分享（P1）

### 11.1 目标

把单篇笔记以只读快照发给他人，接收方无需注册。

### 11.2 元素

| 元素 | 说明 | 规则 |
| --- | --- | --- |
| 分享按钮 | 笔记右上角 | 未同步时先落盘再生成 |
| 分享弹窗 | 链接 + 复制 | 复制成功给轻提示 |
| 有效期 | 7 天 / 永久 | 默认 7 天 |
| 关闭分享 | 弹窗内开关 | 关闭后立即失效 |

### 11.3 规则

1. 分享内容是生成时刻的快照，后续编辑不影响；重新分享生成新链接。
2. 链接为不可猜测随机串，不含用户 ID、笔记 ID。
3. 只读；不展示批注、侧边栏、用户信息。
4. 笔记被删除时链接同步失效。
5. 关闭分享后已打开页面在下次刷新时失效。
6. 分享页不写入任何统计个人身份的信息。

### 11.4 异常与提示

| 情况 | 表现 |
| --- | --- |
| 链接失效 | 「该分享已关闭或过期」，不暴露原因 |
| 生成失败 | 提示重试，不展示空链接 |

### 11.5 本期不做

- 协作编辑、评论、@提及
- 权限细分（可评论 / 可编辑）
- 访问统计
- 密码保护

**验收**

- [ ] 分享后修改原文，已分享页面内容不变。
- [ ] 删除笔记后链接立即不可访问。

### 12.1 目标

用户无需手动卸载重装即可获得新版本，且**更新过程不打断写作、不损坏草稿**。

### 12.2 策略

| 对象 | 一期策略 |
| --- | --- |
| 文案、模板等非可执行配置 | 可在线刷新，保留本地默认与上一可用版本；不下发可执行逻辑 |

| 业务代码、渲染引擎、原生库 | 随签名安装包发布，一期不做热更新 |

### 12.3 交互

1. 启动时静默检查更新；有新版本在设置页与主界面角落提示，不弹阻断式对话框。
2. 下载在后台进行，不影响编辑；下载完成提示「重启后更新」。
3. 用户选择「稍后」则本次会话不重复打扰。

### 12.4 异常与提示

| 情况 | 表现 |
| --- | --- |
| 下载中断 | 继续使用旧版本，下次启动续传或重来 |
| 签名校验失败 | 不安装，提示后丢弃安装包 |
| 安装时仍有未同步草稿 | 先落盘再进入安装流程 |
| 数据库结构升级失败 | 停留在旧版本或进入可恢复状态，不得出现空白数据 |

### 12.5 本期不做

- 业务代码热更新
- 灰度发布与 A/B
- 回滚到旧版本（程序可回退，数据库不承诺回退）

**验收**

- [ ] 下载中断、强杀进程后仍可正常编辑。
- [ ] 升级后离线草稿可读、可继续同步。
- [ ] 表结构迁移失败时有明确提示，且旧数据不丢。

## 14. 安全与隐私

### 14.1 必须拍板的边界

历史设计提出默认端到端加密，而一期需求又含在线正文搜索与免登录分享。**是否允许服务端读取正文，必须在确定正文存储格式与搜索接口之前决定。**

| 选择 | 对产品的直接影响 |
| --- | --- |
| 默认端到端加密 | 服务端只存密文，无法做明文全文检索；搜索改为客户端索引；分享需另设显式发布或接收方解密；多设备密钥恢复纳入验收 |
| 允许服务端处理明文 | 可做服务端搜索与只读快照；需落实传输加密、存储与备份保护、最小权限与日志脱敏，且不宣称「服务端无法解密」 |

### 14.2 无论哪条路线的固定项

1. 个人批注默认仅本人可见，不随公开分享发布。
2. 分享链接只读、可撤销，笔记删除后失效。
3. 系统凭据与密钥放在平台安全存储；不能因为用了本地 SQLite 就假定本地正文已加密。
4. 密码使用成熟加盐哈希；日志不记录正文、密码、令牌。

### 14.3 本期不做

- 端到端加密的具体落地（待 14.1 拍板后回填本文）
- 团队权限与审计日志
- 设备管理与远程登出

**验收**

- [ ] 分享页与导出文件中不出现批注与账号 ID。
- [ ] 服务端日志抽检，无正文与凭据。

## 15. 非功能与验收

### 15.1 平台

Windows 10+、macOS 12+、Android 8.0+；一期仅简体中文，文案集中管理。

### 15.2 性能目标（验收目标，不是现有成绩）

| 场景 | 标准 |
| --- | --- |
| 启动与目录 | 首屏 ≤ 1s，冷启动与热启动分别统计；1000 个目录节点渲染 ≤ 500ms |
| 编辑与批注 | 一万字中文笔记，发布构建按键到出字 ≤ 50ms；含批注时仍可组词、撤销、切换预览 |
| 离线可靠性 | 断网编辑、强杀进程、重启后「已存本地」草稿可恢复 |
| 多设备同步 | 弱网重试不重复写入；并发修改不静默覆盖；恢复网络后可区分待同步、冲突、已同步 |
| 服务端 | 2C2G 上并发保存、同步与目录读取的 P95 延迟、错误率、内存与数据库等待可测 |
| 更新与恢复 | 带未同步草稿升级后可继续编辑；能从异机备份实际恢复 |

### 15.3 部署与容量

初期在 2 核 2GB 服务器验证 `HTTPS 反向代理 → Java 应用 → PostgreSQL`；应用与数据库可同机试运行，限制连接池，监控内存、磁盘与 I/O。**压测前不承诺用户容量。** 一期不引入 Redis、Elasticsearch、消息队列、Kubernetes 或微服务。

### 15.4 数据库交付口径

一期只验收 PostgreSQL。需要其他数据库时，按客户认可的具体产品、版本、操作系统与 CPU 架构适配，通过迁移、驱动、事务、索引与业务回归测试后才可声明支持；不把「兼容 PostgreSQL 协议」当作已适配。

### 15.5 发布门槛

1. P0 功能回归通过。
2. 三端编辑行为一致（§13 三条验收全过）。
3. 已存本地草稿在强杀、断网、升级后不丢。
4. 两台设备改动不互相覆盖。
5. 2C2G 压测数据留档，异常项有结论。
